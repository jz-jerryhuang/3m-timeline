# 3M 讀書會 11 週年紀念時光軸 (2015 - 2026)

> 凝聚跨界夥伴，長達十一載的思辨、科技研討與終身學習之旅。

## 🌟 特色
- **沉浸式 Apple Keynote 開場動效**：沉穩聚焦的大數字翻動與星河漸層背景。
- **全響應式時光軸**：流暢的時間軸設計，涵蓋 2015 至 2026 年共 20 場主題研討與經典回憶。
- **動態簡報與相片輪播**：完整支援 Bento Grid 多媒體排版、高解析度相片 Lightbox 瀏覽及簡報動畫 GIF 自動播放。
- **雲端資料夾一鍵直達**：各主題研討資料夾均與 Google Drive 深度整合，點擊「查看更多」即可開啟雲端原檔。
- **靈活編輯模式**：本機支援即時編輯主題標題、講者名單、重點摘要與相片拖曳排序。
